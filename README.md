# قاعدة بيانات تلاوات الشيخ عبد الباسط محمد عبد الصمد

تم حصر كل التلاوات المتاحة على الموقع الرسمي **quran.iranseda.ir** (پایگاه قرآن ایرانصدا) —
265 ألبومًا مؤكدًا باسم القارئ (نام قاری: عبدالباسط محمد عبدالصمد، ملیت: مصری)،
مع روابط التحميل المباشرة الكاملة لكل تلاوة (وكل الأجزاء إذا كانت التلاوة مقسومة).

## الأقسام
- **المرتل — المصحف كاملًا**: 30 تلاوة
- **المجود — حفلات ومجالس**: 97 تلاوة
- **المجود — استوديو**: 120 تلاوة
- **المجود — الدوريّ**: 18 تلاوة
- **تسجيلات لندن**: 2 تلاوة

## الملفات
- `data/*.csv` و `data/*.json` — قاعدة بيانات كل قسم (الاسم + النوع + رابط/روابط التحميل المباشرة)
- `abdelbasit.db` — قاعدة بيانات SQLite كاملة (جدول recitations)
- `radio/` — أرشيف برنامج راديو تلاوت اليومي (مثال + سكريبت زحف كامل)
- `radio_archive_crawler.py` — سكريبت جلب أرشيف الراديو بالكامل

## صيغة السجلات
كل سجل يحتوي: `id` (معرف التلاوة)، `name` (اسم التلاوة)، `type` (نوعها: مرتل/تحقیق مجود + مجلسی/استودیویی)،
`parts_count` (عدد الأجزاء)، `part_N_link` (رابط التحميل المباشر للجزء N)، `part_N_duration` (مدته)،
`venue` (مكان الأداء)، `read_type` (نوع القراءة)، `series` (السلسلة).

رابط تحميل مباشر مثال: `http://player.iranseda.ir/downloadfile?attid=<attid>&VALID=TRUE&q=11`

## ملاحظة أرشيف الراديو
إذاعة راديو تلاوت تبث يوميًا برنامج «تلاوت قاری مصری عبدالباسط» (~5,200 حلقة من 2011 حتى 2025) —
نفس التلاوات المجودة لكن بترتيب البث. لتحميله كاملًا شغّل `radio_archive_crawler.py` على سيرفر إنترنت عادي.
