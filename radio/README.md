# 06 — أرشيف راديو تلاوت (البرنامج اليومي لعبد الباسط)

البرنامج: **تلاوت قاری مصری - عبدالباسط محمد عبدالصمد** على راديو تلاوت (ایران صدا)
- صفحة البرنامج: http://radio.iranseda.ir/Program/?ch=28&m=165100
- نوع التلاوة: مجود (إذاعي يومي) — كل حلقة ~40 دقيقة
- كل حلقة مقسومة إلى **مقطعين**، وكل مقطع متاح على سيرفرين (8 و 12) = 4 روابط
- الحجم الإجمالي للأرشيف: ~5,200 حلقة (منذ ~2011) — التحميل الكامل عبر السكريبت أدناه
